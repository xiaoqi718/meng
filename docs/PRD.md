# meng - AI 简历优化器 PRD

## 1. 项目概述

**项目名称**：meng  
**产品定位**：面向应届生和职场新人的 AI 简历优化工具  
**核心价值**：上传简历 PDF，3 分钟内获得专业修改建议 + 优化后的简历内容。

## 2. 目标用户

- 应届毕业生（写简历没经验，最焦虑）
- 工作 1-5 年想跳槽的职场人
- 转行/跨行业求职者

## 3. MVP 功能范围（第一阶段）

### 3.1 必须实现
- [x] 用户上传 PDF 简历
- [x] 系统解析简历文本
- [x] 调用大模型分析简历
- [x] 输出：简历评分 + 主要问题 + 修改建议 + 优化后简历
- [x] 用户可以复制优化后的简历

### 3.2 暂不做（第二阶段）
- [ ] 用户登录/注册
- [ ] 支付系统
- [ ] Word/PDF 导出
- [ ] 多轮对话修改
- [ ] 针对岗位 JD 的定向优化
- [ ] 数据库持久化

## 4. 产品流程

```
用户打开网页
  → 上传 PDF 简历
  → 输入/确认 API Key
  → 点击「开始分析」
  → 等待 10-30 秒
  → 查看评分、问题、建议、优化版简历
  → 复制优化结果
```

## 5. 页面结构

### 5.1 首页
- 标题：meng - AI 简历优化器
- 副标题：3 分钟，让你的简历更值钱
- 上传 PDF 区域
- 分析按钮
- 结果展示区域

### 5.2 结果页
- 简历评分（0-100）
- 主要问题（3-5 条）
- 修改建议（3-5 条）
- 优化后的简历（可复制）

## 6. 技术栈

| 模块 | 技术 |
|------|------|
| 前端 | Streamlit |
| 后端 | Python |
| PDF 解析 | pdfplumber |
| 大模型 | DeepSeek API（兼容 OpenAI 格式） |
| 部署 | Streamlit Cloud（免费） |
| 配置 | python-dotenv |

## 7. 成功指标

- 内测阶段：10 人试用，收集反馈
- 上线阶段：100 人访问，5 人付费
- 稳定阶段：月收入 > 500 元

## 8. 风险与应对

| 风险 | 应对 |
|------|------|
| API 成本高 | 使用 DeepSeek，单份简历成本约 0.01-0.05 元 |
| 用户不信任 | 免费试用 + 展示分析示例 |
| PDF 解析失败 | 支持 txt 输入作为兜底 |
| 效果不稳定 | 持续优化 Prompt |

## 9. 后续迭代方向

4. 针对行业/岗位的模板库
5. 面试模拟功能
